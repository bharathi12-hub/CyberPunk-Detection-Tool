# CyberPunk Detection Tool — Documentation

CyberPunk is an AI-powered browser security extension that analyzes websites in real time,
detects malicious behavior, calculates a trust score, and generates explainable security reports.

> **New here?** Start with the **[Complete Guide](GUIDE.md)** — a single end-to-end walkthrough
> of the architecture, every detection engine, the scoring model, and the backend.
